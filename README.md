## ✨ Features

### 🎥 Interview Booking & Sessions
- **Marketplace Browsing**: Discover and book sessions with verified expert interviewers
- **Real-Time Video Calling**: Built-in video interviews powered by Stream
- **In-Session Chat**: Live messaging during interview sessions
- **Session Scheduling**: Flexible booking with interviewer availability
- **Session History**: Complete record of past and upcoming interviews

### 🤖 AI Interview Engine
- **Dynamic Question Generation**: Role-specific questions generated by Google Gemini
- **Automated Feedback**: Post-session performance analysis and scoring
- **Improvement Suggestions**: Personalized tips based on session performance
- **Question Bank**: AI-curated question sets per domain and difficulty

### 💳 Credits & Payments
- **Credit Wallet**: Purchase and manage interview credits
- **Booking System**: Spend credits to book sessions with interviewers
- **Interviewer Payouts**: Earn and withdraw credits per completed session
- **Admin Payout Panel**: Secure admin interface for managing payouts
- **Transaction History**: Full ledger of credit activity

### 🔐 Authentication & Security
- **Clerk Authentication**: Secure sign-up, sign-in, and session management
- **Role-Based Routing**: Separate flows for candidates and interviewers
- **Protected Routes**: Middleware-enforced access control
- **Arcjet Protection**: Rate limiting and bot protection on all routes

### 📩 Notifications
- **Automated Emails**: Booking confirmations and session reminders via Resend
- **In-App Feedback**: Post-session reports delivered to candidates
- **Status Updates**: Real-time booking status notifications

## 🔑 Key Features Explained

### 1. AI-Powered Interview Questions

Prept uses **Google Gemini** to generate role-specific interview questions dynamically before each session:

```typescript
// Generate questions for a session
const questions = await generateInterviewQuestions({
  role: "Senior Frontend Engineer",
  level: "senior",
  topics: ["React", "TypeScript", "System Design"],
  count: 10,
});

// Gemini returns structured output:
// [
//   { question: "Explain React's reconciliation algorithm", difficulty: "hard" },
//   { question: "How would you structure a large TypeScript project?", difficulty: "medium" },
//   ...
// ]
```

### 2. Real-Time Video Sessions

Sessions are powered by **Stream**, giving candidates and interviewers a full video + chat experience without leaving the platform:

```typescript
// Create a video call for a booked session
const call = client.call("default", sessionId);
await call.getOrCreate({
  data: {
    members: [
      { user_id: candidateId, role: "member" },
      { user_id: interviewerId, role: "host" },
    ],
  },
});
```

### 3. Credit-Based Booking System

The platform uses a credit wallet model:

- Candidates purchase credit bundles
- Each booking deducts credits from the candidate's wallet
- On session completion, credits are transferred to the interviewer
- Interviewers request payouts through the admin panel

```typescript
// Book a session — deduct from candidate, hold for interviewer
await prisma.$transaction([
  prisma.wallet.update({
    where: { userId: candidateId },
    data: { credits: { decrement: session.creditCost } },
  }),
  prisma.booking.create({
    data: { candidateId, interviewerId, sessionId, status: "CONFIRMED" },
  }),
]);
```

### 4. Automated Post-Session Feedback

After each session, Gemini analyzes the interview and generates a structured feedback report sent directly to the candidate via email:

```typescript
// Generate feedback from session transcript
const feedback = await generateFeedback({
  transcript: session.transcript,
  role: session.role,
  questionsAsked: session.questions,
});

// Output includes:
// { overallScore: 78, strengths: [...], improvements: [...], summary: "..." }

await sendFeedbackEmail({ to: candidate.email, feedback });
```

### 5. Role-Based Access with Clerk

Prept supports two user roles — **candidate** and **interviewer** — enforced at the route and server action level:

```typescript
// Protect server actions by role
const { userId } = auth();
const user = await prisma.user.findUnique({ where: { clerkId: userId } });

if (user.role !== "INTERVIEWER") {
  throw new Error("Unauthorized");
}
```

## 🚀 Deployment

This project is deployed on **[Vercel](https://vercel.com)**.

### Live Demo

- **Production URL:** [https://prept-lovat.vercel.app/](https://prept-lovat.vercel.app/)

To deploy your own instance:

1. Fork this repository and import it into Vercel
2. Add all environment variables from the `.env` template above
3. Set `NEXT_PUBLIC_APP_URL` to your Vercel domain
4. Set `ARCJET_ENV="production"`
5. Run `npx prisma db push` against your production database
6. Deploy — Vercel auto-builds on every push to `main`

### Pre-Deployment Checklist

- [ ] All environment variables configured on Vercel
- [ ] Production PostgreSQL database provisioned and connected
- [ ] All API keys verified (Clerk, Stream, Gemini, Resend, Arcjet)
- [ ] `ARCJET_ENV` set to `"production"`
- [ ] `ADMIN_PAYOUT_PASSWORD` changed from the default value
- [ ] `npm run build` passes locally with no errors

## ⚠️ Troubleshooting

**Dev lock error on Windows** — if the dev server crashes and won't restart:

```bash
Remove-Item -Recurse -Force .next\dev
npm run dev
```

**Protected routes throwing errors in development** — ensure `ARCJET_ENV="development"` is set in `.env`, then restart the server. Arcjet enforces stricter rules in production mode.

**Prisma client not found** — run `npx prisma generate` after cloning or after any schema change.

**Stream video not connecting** — verify `NEXT_PUBLIC_STREAM_API_KEY` is correct and that your Stream app has the video product enabled in the Stream dashboard.
